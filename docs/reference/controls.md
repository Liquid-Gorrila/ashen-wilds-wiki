# Controls

Attacks aim at the mouse cursor when you use the mouse, otherwise in the direction you're moving or facing.

| Action | Keyboard | Mouse |
| --- | --- | --- |
| Move | ++w++ ++a++ ++s++ ++d++ or arrow keys | |
| Slash (light attack) | ++j++ | Left click |
| Chop (heavy attack, costs stamina) | ++k++ | Right click |
| Roll (dodge, costs stamina) | ++space++ or ++shift++ | |
| Use / interact | ++e++ | |
| Eat best food | ++f++ | |
| Throw a Flame Bottle | ++q++ | Aims at the cursor |
| Throw a Poison Bottle | ++g++ | Aims at the cursor |
| Next recipe at a station that crafts more than one thing | ++r++ | |
| Build menu | ++c++ or ++tab++ | |
| Dismantle | ++x++ | |
| Pause | ++esc++ or ++p++ | |
| FPS counter | ++f3++ | |

## Build menu

| Action | Key |
| --- | --- |
| Switch category tab | ++a++ / ++d++ |
| Choose a structure | ++w++ / ++s++ |
| Build at the green ghost | ++e++, ++enter++ or left click |
| Rotate belts, transporters, filters, splitters and flamethrowers | ++r++ |
| Close | ++c++ or ++esc++ |

## Speed Racer

While riding the [Speed Racer](../world/speed-racer.md), the movement keys steer, ++e++ gets off and ++f++ still eats.

## Menus

The title, pause and settings menus use ++w++ / ++s++ or the arrow keys to move, ++e++ or ++enter++ to choose, and ++a++ / ++d++ to adjust sliders. The mouse works too.
